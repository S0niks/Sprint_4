# qa_python

# Список тестов

1. test_add_new_book_valid - параметризованный: проверяет добавление книг с названиями минимальной (1 символ) и максимальной (40 символов) длины, а также обычное название
2. test_add_new_book_invalid_name - параметризованный: проверяет, что пустое название или строка длиннее 40 символов не добавляются
3. test_set_book_genre_valid - книга добавляется, затем ей успешно устанавливается допустимый жанр
4. test_set_book_genre_invalid - параметризованный: проверяет, что жанр не устанавливается для несуществующей книги и для недопустимого жанра
5. test_get_books_with_specific_genre - среди нескольких книг с разными жанрами возвращается только список книг запрошенного жанра
6. test_get_books_for_children - проверяет, что в результат попадают книги только с «детскими» жанрами (без возрастного рейтинга)
7. test_add_book_in_favorites - книга добавляется в избранное; повторное добавление не создаёт дубликат
8. test_delete_book_from_favorites - удаление книги из избранного, удаление отсутствующей книги не ломает логику
9. test_get_list_of_favorites_books_empty - изначально список избранных книг пуст
